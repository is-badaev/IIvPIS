
# Лабораторные работы по дисциплине «Искусственный интеллект в программно-информационных системах»

## 📘 Описание курса

Цель дисциплины — формирование у обучающихся базовых навыков работы с инструментами анализа данных, визуализации и машинного обучения с использованием языка программирования Python и соответствующих библиотек.

## ⚙️ Среда разработки
- Язык: Python 3.9
- Основная среда: **IDLE Python**, возможна работа в PyCharm
- Основные библиотеки: `pandas`, `matplotlib`, `seaborn`

Установка зависимостей:
```bash
pip install -r requirements.txt
```
